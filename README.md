# 駅ルーレット

大都市圏の路線を選んで、その路線の駅から 1 駅をルーレットで選ぶ、スマホ向けの Web アプリです (はじめは山手線ルーレットとして作りました)。

## 使い方

- 上の「地域」「路線」のプルダウンで路線を選びます。複数の都道府県にまたがる路線は、それぞれの地域に出ます
- 「回す」を押すか盤をタップすると盤が回り、電車の顔の下で止まった駅が選ばれます
- 選ばれた駅は下の看板に、駅番号・よみがな・ローマ字・となりの駅と一緒に出ます。看板やボタンは路線の色になります。「地図」で Google マップのその駅の位置を開けます
- 最後に選んだ路線は、次に開いたときも残ります (端末の中だけに保存)
- ブラウザの「ホーム画面に追加」でアプリのように使えます。一度開けば電波が無くても動きます

## しくみ

- どの駅も同じ確率です。抽選は `crypto.getRandomValues` で先に行い、盤はその駅で止まるように回ります
- 盤の駅の並びは路線の順です。環状線 (山手線・大阪環状線・名城線・札幌市電・ディズニーリゾートライン) は、北が上の路線図と同じ巡りです
- 41 駅以上の路線は、盤には駅の丸だけを描き、駅名は看板に出します。長い駅名は盤の上で 2 列に折ることがあります
- 端末で「視差効果を減らす」がオンのときは、盤を回さずにすぐ結果を出します
- 外部へのデータ送信はありません (地図を開いたときに Google マップへ駅の位置を渡すのを除く)

## 地域と路線

- 首都圏 (東京・神奈川・埼玉・千葉)・関西 (大阪・京都・兵庫・奈良)・名古屋 (愛知)・福岡・札幌 (北海道は札幌市に駅がある路線)
- JR の在来線・地下鉄・私鉄・第三セクター・モノレール・新交通・路面電車。新幹線とケーブルカーは入れていません

## 開発

- ビルド不要の HTML / CSS / JavaScript です。`python3 -m http.server` などで配信して開きます
- テスト: `node --test`

## データ

- 路線と駅 (並び・よみ・ローマ字・駅番号・位置・路線の色): [TrainLCD/StationAPI](https://github.com/TrainLCD/StationAPI) の `data` (MIT License, Copyright (c) 2019 TinyKitten)。ライセンスの全文は `data/LICENSE-TrainLCD.txt` です。使った版は `data/lines.json` の `source` に書いています
- 一部の駅番号・よみ・並び・区間は、Wikipedia の駅一覧と照らして直しています。快速の路線には、快速が止まる駅だけを入れています (駅番号で判断)。信号場は入れていません
- 非公式のアプリです。鉄道会社とは関係ありません
