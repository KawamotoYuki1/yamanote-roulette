# 山手線ルーレット

山手線の 30 駅から 1 駅をルーレットで選ぶ、スマホ向けの Web アプリです。

## 使い方

- 「回す」を押すか盤をタップすると盤が回り、針の下で止まった駅が選ばれます
- 選ばれた駅は下のプレートに、駅番号・よみがな・ローマ字・となりの駅と一緒に出ます。「地図」から Google マップを開けます
- ブラウザの「ホーム画面に追加」でアプリのように使えます。一度開けば電波が無くても動きます

## しくみ

- 30 駅とも同じ確率 (1/30) です。抽選は `crypto.getRandomValues` で先に行い、盤はその駅で止まるように回ります
- 端末で「視差効果を減らす」がオンのときは、盤を回さずにすぐ結果を出します
- 外部へのデータ送信はありません (地図を開いたときの Google マップを除く)

## 開発

- ビルド不要の HTML / CSS / JavaScript です。`python3 -m http.server` などで配信して開きます
- テスト: `node --test`

## データ

- 駅名・駅番号 (JY01〜JY30)・よみがな・ローマ字は、各駅の公開情報をもとにしています (2026年11月時点)
- 盤の駅の並びは、北が上の路線図と同じ巡りです
- 非公式のアプリです。JR東日本とは関係ありません

## フォント

- Noto Sans JP と League Spartan (どちらも SIL Open Font License 1.1) を、アプリで使う文字だけに絞って `fonts/` に入れています。ライセンスの全文は `fonts/OFL-*.txt` です
